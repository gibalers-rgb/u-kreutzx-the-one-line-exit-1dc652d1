A program that writes the funniest single-line resignation letter it can: a museum night guard quits because the T. rex has started following him home, and HR refuses to call it overtime. One line, 123 characters, specific voice, surprise punchline — built for make.fun's "The One-Line Exit" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It writes the letter to `/output/entry.txt` (validating the 1–140 character, single-line gate first, then reading the file back to confirm it round-trips intact).
